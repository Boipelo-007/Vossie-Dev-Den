# Vossie Dev Den

A static website for the Vossie Dev Den student coding club.

## Pages

- `index.html` - Home
- `about.html` - Club information and executive team
- `events.html` - Upcoming coding club events
- `projects.html` - Featured projects
- `resources.html` - Coding learning resources
- `contact.html` - Social media links
